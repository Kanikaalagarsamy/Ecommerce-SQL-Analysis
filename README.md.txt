
# E-Commerce Sales & Customer Analysis using MySQL

## Project Overview
This project focuses on analysing e-commerce sales,
customer purchasing behaviour, product performance,
and payment trends using MySQL.

The objective is to use SQL queries to extract
meaningful business insights from e-commerce data.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Database Design

The project contains five relational tables:

1. Customers
2. Products
3. Orders
4. Order_Details
5. Payments

Primary keys and foreign keys are used to establish
relationships between the tables.

## SQL Concepts Implemented

- Database and table creation
- Primary and Foreign Keys
- SELECT, INSERT and WHERE
- ORDER BY and LIMIT
- Aggregate Functions
- GROUP BY and HAVING
- INNER JOIN, LEFT JOIN and RIGHT JOIN
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- ROW_NUMBER(), RANK() and DENSE_RANK()
- LAG()
- SQL Views

## Business Analysis

The project answers the following business questions:

1. What is the total paid revenue?
2. Which month generated the highest revenue?
3. Which products generate the most revenue?
4. Who are the highest-spending customers?
5. Which cities generate the most revenue?
6. Who are the repeat customers?
7. Which payment method is most popular?
8. What is the order status distribution?
9. What are the cancelled and refunded orders?
10. Which product category performs best?
11. What is the average order value?

## Key Findings

- Total paid revenue: ₹253,000
- Total paid orders: 12
- Total customers: 10
- Total products: 10
- July revenue was higher than June revenue.
- Electronics generated the highest category revenue.
- Laptops generated the highest individual product revenue.

## How to Run the Project

1. Install MySQL Server and MySQL Workbench.
2. Open 01_Database.sql and execute it.
3. Execute 02_Create_Tables.sql.
4. Execute 03_Insert_Data.sql.
5. Execute the remaining SQL files in numerical order.
6. Review the query outputs in MySQL Workbench.

Note: Run the database, table creation and sample
data scripts on a fresh project database.
